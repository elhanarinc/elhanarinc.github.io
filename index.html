WiFi Checker

Monitor your Wi-Fi health in real-time from your menu bar. Track signal strength, latency, packet loss, and run speed tests — all in one lightweight app.

Download on Mac App Store

Features

📶

Real-Time Monitoring

Track signal strength, link rate, noise level, and frequency band in real-time.

📊

Network Diagnostics

Monitor ping, jitter, and packet loss to both your router and the internet.

⚡

Speed Testing

Run speed tests using Cloudflare servers without leaving the app.

🔍

DNS Analysis

Measure DNS lookup time and identify potential DNS issues.

🔒

Privacy-First

100% read-only operation. No data collection, no tracking, no account required.

🎯

Menu Bar App

Lives in your menu bar — always one click away when you need it.
