Privacy Policy

Last updated: January 25, 2026

Summary

WiFi Checker does not collect, store, or transmit any personal data. All network measurements are processed locally on your device and never leave your Mac.

Information We Don't Collect

WiFi Checker is designed with privacy as a core principle. We do not collect:

  • Personal information
  • Network names or passwords
  • Location data
  • Usage analytics
  • Crash reports
  • Any other data

Location Services

WiFi Checker requests Location Services permission solely to access your Wi-Fi network name (SSID), as required by macOS Sonoma and later. This is an Apple requirement for accessing Wi-Fi information.

We do not:

  • Track your location
  • Store location data
  • Transmit location information

Network Requests

WiFi Checker makes network requests only for the following purposes:

  • Ping tests: TCP connections to your router and Cloudflare (1.1.1.1) to measure latency
  • Speed tests: Connections to Cloudflare speed test servers (speed.cloudflare.com) when you manually initiate a speed test
  • DNS tests: DNS lookups to measure resolution time

No personal data is transmitted in these requests.

Data Storage

All data displayed in WiFi Checker (signal strength, ping times, speed test results, etc.) is stored only in memory and is cleared when you quit the app. Nothing is written to disk or synced to any server.

Third-Party Services

WiFi Checker does not integrate with any third-party analytics, advertising, or tracking services.

Children's Privacy

WiFi Checker does not collect any personal information from anyone, including children under 13.

Changes to This Policy

We may update this Privacy Policy from time to time. Any changes will be posted on this page with an updated revision date.
